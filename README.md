# Nicola Benetti — Professional Webpage

Pagina personale realizzata con design **Bento Grid** minimale e responsive, ospitata gratuitamente su **GitHub Pages**.

🌐 **Live:** [https://nicoxl.github.io/](https://nicoxl.github.io/)

## ✨ Caratteristiche
- **Layout Bento Grid:** Griglia modulare sviluppata con CSS Grid moderno, adattabile a desktop, tablet e smartphone.
- **Zero dipendenze:** Singolo file `index.html` con CSS e favicon SVG vettoriale integrati, per caricamenti istantanei.
- **Contatti e progetti:** Collegamenti rapidi ai profili social, email diretta e progetti sviluppati (tra cui [JDLed Illuminazione](https://jdledprojectlux.com)).

## 🛠️ Tecnologie utilizzate
- HTML5 semantico
- CSS3 (CSS Grid, variabili custom, animazioni hover)
- GitHub Pages per l'hosting statico

Studente di Informatica presso l'**Università di Verona (UniVR)** con la passione per lo sviluppo web e la realizzazione di soluzioni digitali su misura.
